Do AI-generated tests actually catch defects?

Buggy hosts small applications with a catalog of deliberately seeded defects, runs competing test suites against every defective build, and measures which suite caught which defect. The output is a detection matrix and per-suite scorecards, not a green badge.

A seeded defect is a mutant. This is mutation testing turned around: instead of using mutants to grade the code, Buggy uses them to grade the test suites. A suite only scores when it fails on a defective build and passes on the clean one - anything else is a false positive, not a finding.
