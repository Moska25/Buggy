Competing test suites

Four suites, the same three targets, the same seeded defects. The only variable is who wrote the checks and what they could see while writing them.

Provenance, stated plainly. The two suites labelled recorded fixture are Python files committed to this repository. They were authored once to represent their condition - spec-only, and code-reading - and checked in so the benchmark is reproducible and runs offline. Buggy never calls a model at run time, requires no API key, and does not regenerate a suite live. Live generation is a documented future phase and is not built. Nothing on this page is the output of an agent running now.
